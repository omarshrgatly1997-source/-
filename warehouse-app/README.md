# تطبيق إدارة المستودعات (Warehouse Management System)

مشروع جديد ومستقل داخل هذا الريبو (لا علاقة له بمشروع "نخبة التداول" الموجود في
`web/`). هذا المجلد يحتوي حتى الآن على **مرحلة التخطيط**: المعمارية، تصميم
قاعدة البيانات، وخارطة الطريق، قبل البدء في كتابة أي واجهات أو منطق أعمال.

## نطاق المشروع (متفق عليه)

- **الاستخدام**: شركة واحدة تدير **عدة مستودعات/فروع** من نظام واحد.
- **المنصة**: **ويب فقط** (لوحة تحكم تعمل من المتصفح على كمبيوتر أو تابلت/موبايل
  داخل المستودع، بدون تطبيق موبايل native).
- **قاعدة البيانات**: PostgreSQL.
- **نقطة البداية العملية**: تصميم قاعدة البيانات والمعمارية أولاً (هذا المجلد)،
  قبل أي كود واجهة أو منطق تشغيلي.

## الخطوة التالية

بعد اعتماد هذا التصميم، الخطوة التالية المقترحة هي تهيئة مشروع Next.js فعلي
داخل `warehouse-app/` (على نفس نمط `web/` الموجود بالريبو)، وربط سكيمة Prisma
هذه بقاعدة بيانات حقيقية، ثم البدء بشاشات المرحلة الأولى (Products, Warehouses,
Stock Movements) كما هي موضحة في `docs/roadmap.md`.
