# تطبيق إدارة المستودعات (Warehouse Management System)

مشروع جديد ومستقل داخل هذا الريبو (لا علاقة له بمشروع "نخبة التداول" الموجود في
`web/`). Next.js + PostgreSQL لإدارة المخزون عبر عدة مستودعات/فروع، بصلاحيات
مستقلة لكل مستودع.

## نطاق المشروع (متفق عليه)

- **الاستخدام**: شركة واحدة تدير **عدة مستودعات/فروع** من نظام واحد.
- **المنصة**: **ويب فقط** (لوحة تحكم تعمل من المتصفح على كمبيوتر أو تابلت/موبايل
  داخل المستودع، بدون تطبيق موبايل native).
- **قاعدة البيانات**: PostgreSQL.

## التقنية

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Prisma 7 + PostgreSQL
· جلسات مبنية على JWT موقّعة (نفس نمط مشروع `web/` الموجود بالريبو).

## الحالة الحالية (المرحلة 1 و2 من `docs/roadmap.md` منجزتين)

- تسجيل دخول/حساب بجلسات JWT. أول حساب بنفس بريد `ADMIN_EMAIL` يُنشئ مستودعًا
  افتراضيًا ("المستودع الرئيسي") ويصبح **أدمن عام** تلقائيًا؛ أي حساب تاني
  بيوصل لصفحة `/pending` لحد ما أدمن يمنحه صلاحية على مستودع.
- لوحة إدارة (`/dashboard/admin`، للأدمن العام فقط): إنشاء مستودعات، ومنح/إلغاء
  صلاحية مستخدم على مستودع (الأدوار: أدمن، مدير مستودع، أمين مخزن، محاسب، مشاهد).
- كتالوج أصناف مشترك بين كل المستودعات (`/dashboard/products`).
- الموردين (`/dashboard/suppliers`) + شراء واستلام بضاعة من مورد (صنف واحد لكل
  عملية، بيتسجّل كأمر شراء + إذن استلام + حركة `RECEIPT_IN`).
- العملاء (`/dashboard/customers`) + بيع وصرف بضاعة لعميل (نفس مستوى التبسيط،
  بيتسجّل كأمر بيع + إذن صرف + حركة `ISSUE_OUT`، مع منع البيع لو الرصيد غير كافٍ).
- حركات مخزون يدوية (إدخال/صرف) لكل مستودع.
- تحويل بضاعة بين مستودعين (`StockTransfer`)، بيولّد حركتي `TRANSFER_OUT`
  و`TRANSFER_IN` معًا.
- كل حركات المخزون بترجع لرصيد يُحسب من سجل الحركات (Ledger) داخل معاملة
  (transaction) واحدة، مع منع أي عملية تُنقص الرصيد عن الصفر.
- لوحة تحكم لكل مستودع: عدد الأصناف برصيد، قيمة المخزون الإجمالية، وسجل آخر
  15 حركة.

**محدوديات معروفة في هذه المرحلة** (موثّقة في التعليقات بالكود، ومتابَعة في
`docs/roadmap.md`): الأرصدة لسه مش مقسّمة حسب الموقع/الدفعة داخل المستودع، كل
الأصناف بتستخدم وحدة قياس افتراضية واحدة، الشراء والبيع صنف واحد بس لكل عملية
وبيتمّوا فورًا (بدون دورة حياة أمر شراء/بيع كاملة)، ومفيش سير موافقات على
العمليات.

## الإعداد المحلي

```bash
cd warehouse-app
npm install
cp .env.example .env   # واملأ DATABASE_URL / AUTH_SECRET / ADMIN_EMAIL
npx prisma migrate dev
npm run dev
```

افتح `http://localhost:3000/register` وسجّل حساب بالبريد المطابق لـ
`ADMIN_EMAIL` لتصبح أدمن عام تلقائيًا (بيتنشئ معاه مستودع افتراضي)، وبعد كده من
`/dashboard/admin` تقدر تنشئ مستودعات إضافية وتمنح صلاحيات لباقي المستخدمين.
