# نخبة التداول — منصة استراتيجيات التداول الخاصة

منصة ويب خاصة (Next.js + PostgreSQL) لنشر استراتيجيات تداول بشرح احترافي، بدخول
محصور بموافقة يدوية من الإدارة، مع مساعد ذكي (مبني على Claude API) يجيب عن أسئلة
الأعضاء حول الاستراتيجيات المنشورة، ولوحة إدارية لمتابعة كل مستخدم على حدة.

## المزايا

- **دخول خاص بالموافقة**: أي شخص يسجّل حسابًا يبقى بحالة "بانتظار الموافقة" حتى
  يوافق عليه المدير من لوحة الإدارة؛ عندها فقط يمكنه تسجيل الدخول.
- **نشر الاستراتيجيات**: لوحة إدارية لإنشاء/تعديل/نشر استراتيجيات بشرح كامل
  (يدعم Markdown)، مع تصنيف مستوى المخاطرة.
- **مساعد ذكي**: صفحة دردشة لكل عضو مفعّل، مبنية على Anthropic Claude API،
  مؤسسة على محتوى الاستراتيجيات المنشورة فقط، مع حفظ سجل المحادثة.
- **متابعة كل عضو**: صفحة إدارية لكل مستخدم على حدة (`/admin/users/[id]`) وقاعدة
  بيانات جاهزة لتسجيل التداولات (`Trade` model) تمهيدًا لتفعيل الإدخال لاحقًا.

## التقنية

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Prisma 7 + PostgreSQL ·
جلسات مبنية على JWT موقّعة (بدون خدمة خارجية) · Anthropic SDK للمساعد الذكي.

## الإعداد المحلي

1. **قاعدة البيانات**: أنشئ قاعدة بيانات PostgreSQL وضع رابط الاتصال في
   `DATABASE_URL` داخل ملف `.env` (انظر `.env` الحالي كمثال).
2. **متغيرات البيئة** (`.env`):
   - `DATABASE_URL` — رابط اتصال PostgreSQL.
   - `AUTH_SECRET` — نص عشوائي قوي (32 حرفًا فأكثر) لتوقيع جلسات الدخول.
   - `ADMIN_EMAIL` — البريد الإلكتروني الذي سيُصبح صاحبه **مديرًا مفعّلًا تلقائيًا**
     أول مرة يسجّل بها حسابًا (بشرط ألا يوجد مدير آخر من قبل). استخدمه لإنشاء أول
     حساب إداري دون الحاجة لموافقة يدوية.
   - `ANTHROPIC_API_KEY` — مفتاح Anthropic API لتفعيل المساعد الذكي.
3. **التثبيت والتشغيل**:
   ```bash
   npm install
   npx prisma migrate deploy   # أو migrate dev أثناء التطوير
   npm run dev
   ```
4. افتح `http://localhost:3000`، سجّل حسابًا بالبريد المطابق لـ `ADMIN_EMAIL`
   لتصبح مديرًا، ثم من لوحة `/admin` وافق على بقية الحسابات ونشر الاستراتيجيات.

## النشر (Deployment)

يحتاج المشروع استضافة تدعم Node.js (وليس استضافة ثابتة/Static) لأن المصادقة
والمساعد الذكي يعملان عبر Server Actions و Route Handlers، بالإضافة إلى قاعدة
بيانات PostgreSQL مُدارة (مثل Neon أو Supabase أو Vercel Postgres). اضبط متغيرات
البيئة الأربعة أعلاه في إعدادات بيئة الاستضافة، ثم شغّل `npx prisma migrate deploy`
عند كل نشر لتطبيق أي تغييرات على قاعدة البيانات.

## بنية جاهزة للمستقبل

جدول `Trade` في `prisma/schema.prisma` جاهز لتخزين تداولات كل مستخدم (الرمز،
الاتجاه، سعر الدخول/الخروج، الربح/الخسارة...)، وصفحة `/admin/users/[id]` تعرضها
بالفعل إن وُجدت. يبقى فقط إضافة واجهة لإدخال التداولات (يدويًا أو عبر ربط API
من منصة تداول) عند الحاجة لاحقًا.
