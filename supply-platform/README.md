# التوريد العالمي — منصة توريد أي منتج أو خدمة (قانونيًا)

منصة ويب (Next.js + PostgreSQL) تتيح لأي عميل تقديم طلب توريد لأي منتج أو
خدمة يحتاجها، بغض النظر عن الفئة، على أن يكون الطلب قانونيًا بالكامل. فريق
التوريد يراجع كل طلب، يبحث عن أفضل مصدر وسعر، ويرد بعرض سعر رسمي يمكن للعميل
قبوله أو رفضه، مع سجل مراسلات مباشر ولوحة إدارة كاملة لمتابعة كل الطلبات.

## المزايا

- **طلب توريد مفتوح لأي فئة**: العميل يصف حاجته بحرية (منتج، معدات، مواد خام،
  خدمة...) مع الكمية والميزانية والموعد المطلوب.
- **بوابة امتثال قانوني**: قائمة صريحة بالممنوعات (أسلحة، مخدرات، اتجار
  بالبشر، سلع مقلدة أو مسروقة، أنواع مهددة بالانقراض، مواد خطرة بلا تراخيص،
  أي شيء يخالف العقوبات الدولية) + إقرار إلزامي من العميل قبل الإرسال، وزر
  رفض فوري للإدارة مع سبب يظهر للعميل.
- **عروض أسعار وتتبع حالة**: كل طلب يمر بحالات واضحة (جديد → قيد المراجعة →
  عرض سعر → مقبول/مرفوض → تم التوريد)، والعميل يقبل أو يرفض عرض السعر من
  حسابه مباشرة.
- **مراسلات لكل طلب**: سجل محادثة بين العميل والإدارة مرتبط بكل طلب على حدة.
- **لوحة إدارة**: نظرة عامة على الإحصائيات، قائمة كل الطلبات مع فلترة حسب
  الحالة، وصفحة تفصيلية لكل طلب لإرسال عروض الأسعار وتغيير الحالة.

## التقنية

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Prisma 7 + PostgreSQL
· جلسات مبنية على JWT موقّعة (بدون خدمة خارجية).

## الإعداد المحلي

1. **قاعدة البيانات**: أنشئ قاعدة بيانات PostgreSQL وضع رابط الاتصال في
   `DATABASE_URL` داخل ملف `.env` (انظر `.env.example`).
2. **متغيرات البيئة** (`.env`):
   - `DATABASE_URL` — رابط اتصال PostgreSQL.
   - `AUTH_SECRET` — نص عشوائي قوي (32 حرفًا فأكثر) لتوقيع جلسات الدخول.
   - `ADMIN_EMAIL` — البريد الإلكتروني الذي سيُصبح صاحبه **مديرًا تلقائيًا**
     أول مرة يسجّل بها حسابًا (بشرط ألا يوجد مدير آخر من قبل).
3. **التثبيت والتشغيل**:
   ```bash
   npm install
   npx prisma migrate deploy   # أو migrate dev أثناء التطوير
   npm run dev
   ```
4. افتح `http://localhost:3000`، سجّل حسابًا بالبريد المطابق لـ `ADMIN_EMAIL`
   لتصبح مديرًا، ومن `/admin/requests` راجع طلبات العملاء وأرسل عروض الأسعار.

## النشر (Deployment)

يحتاج المشروع استضافة تدعم Node.js (وليس استضافة ثابتة/Static) لأن المصادقة
تعمل عبر Server Actions و Route Handlers، بالإضافة إلى قاعدة بيانات PostgreSQL
مُدارة (مثل Neon أو Supabase أو Vercel Postgres). اضبط متغيرات البيئة الثلاثة
أعلاه في إعدادات بيئة الاستضافة، ثم شغّل `npx prisma migrate deploy` عند كل
نشر لتطبيق أي تغييرات على قاعدة البيانات.

## أفكار للتوسع لاحقًا

- مساعد ذكي (AI) لمساعدة العميل على صياغة طلبه أو للإدارة على تسعيره الأولي.
- تكامل مدفوعات لتحصيل دفعة عند قبول عرض السعر.
- صفحة إدارة للمستخدمين وتقارير أداء (متوسط زمن الرد، معدل القبول...).
- دعم مرفقات (صور/مستندات مواصفات) على الطلب وعروض الأسعار.
